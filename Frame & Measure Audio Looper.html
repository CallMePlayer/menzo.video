Frame & Measure Audio Looper

Timecode: 00:00:00 Frame: 0 Position: 00:00.000

Load an audio file to begin.

Loop in Loop out Drag either marker to move it; dragging switches to Frames mode.

In Frames mode, the loop includes the start frame up to—but not including—the end frame. In Measures mode, it starts at the start measure and ends at the start of the measure after the selected end measure.
